**OmniHub** is a high-performance, developer-first universal directory curated for discovering top Model Context Protocol (MCP) servers, AI agent skills, free cloud databases, free hosting, UI component libraries, GitHub repositories, and essential online dev utilities.

Created with ❤️ by **[Ratul](https://mh-ratul.vercel.app/)**.

---

## ✨ Features & Highlights

- **⚡ Model Context Protocol (MCP) & Agent Skills:** Curated collection of high-performance MCP servers for **Claude Code**, **Antigravity AI**, **Cursor**, and **Windsurf** (e.g., *Smithery.ai Marketplace, Linear MCP, Firecrawl LLM Scraping, Supabase MCP, Neon Postgres MCP, Vercel Deployment MCP, Cloudflare Workers MCP, Perplexity AI Search MCP, Replicate Model MCP*).
- **🎨 Copy-Paste UI & Assets:** Popular UI libraries including *Shadcn UI, Aceternity UI, Magic UI, Tailwind CSS, Lucide Icons, and Fontshare*.
- **🤖 Artificial Intelligence & LLMs:** State-of-the-art AI coding assistants, prompt-to-app tools, research labs (*DeepSeek R1, Claude 3.7, ChatGPT o3, Cursor, Windsurf, Ollama*).
- **🎁 Free Developer Tier Directory:** High-value free databases (*Supabase, Neon, Turso, Firebase*), free cloud hosting (*Vercel, Netlify, Render, Cloudflare Pages, Oracle Always Free 24GB RAM*), free SSL domains, and free LLM API providers (*Groq, Together AI, OpenRouter*).
- **📩 Direct Email Resource Submissions:** Submit custom site recommendations connected to an automated email webhook powered by **FormSubmit.co**.
- **🔖 Bookmark Management:** Save favorite tools locally in browser storage with instant sidebar counters.
- **🛡️ Smart Favicon Engine:** DuckDuckGo Global Icon CDN integration with deterministic HSL monogram fallback avatars for 100% network clean loading.
- **📱 100% Responsive Architecture:** Mobile slide-in drawer, horizontal touch subcategory pills, and auto-fit responsive grid.

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Ratul-NotFound/OmniHub.git

# Navigate to project directory
cd OmniHub

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Production Build & Verification

To compile the production bundle:

```bash
npm run build
```

The optimized static build output will be generated inside the `dist/` directory.
