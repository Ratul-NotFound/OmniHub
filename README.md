# OmniHub — The Universal Hub of Everything 🌐

OmniHub is a modern, ultra-fast, clean, and responsive universal directory for discovering top AI tools, free databases, free cloud hosting, SSL domains, UI design assets, front-end libraries, and developer utilities.

## ✨ Features

- **⚡ Blazing Fast Performance:** Powered by Vite, React, and TypeScript.
- **🎨 Raw Developer Aesthetic:** Clean monochrome dark/light UI inspired by modern design systems.
- **🤖 Dedicated AI Tools Directory:** 10 granular subcategories covering LLMs, AI Coding, Prompt-to-App builders, Model Hubs, Presentations, Diagrams, UI/UX, Image Gen, Video Gen, and Audio.
- **🎁 Free Resources Section:** Dedicated portal for Free Databases (Firestore, Supabase, Neon, Turso), Free Cloud Hosting (Vercel, Netlify, Render, Cloudflare, Oracle Cloud 24GB RAM Free), Free Domains & SSL, and Free LLM APIs.
- **🔗 Multi-Subcategory Matching:** Multi-purpose tools like Firebase and Supabase appear seamlessly across all relevant subcategories.
- **🔍 Instant Search & Keyboard Shortcuts:** Filter by title, description, tags, or URLs with instant feedback (`/` or `Ctrl+K` to search).
- **🔖 Bookmark & Custom Resource Submission:** Save favorite tools locally in browser storage and submit custom links.

## 🛠️ Built With

- **Framework:** [React 19](https://react.dev) + [TypeScript](https://www.typescriptlang.org)
- **Build Tool:** [Vite](https://vitejs.dev)
- **Styling:** CSS Modules with flat HSL monochrome tokens
- **Icons:** [Lucide React](https://lucide.dev)

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Ratul-NotFound/OmniHub.git

# Navigate to directory
cd OmniHub

# Install dependencies
npm install

# Run dev server
npm run dev
```

## 📦 Build for Production

```bash
npm run build
```
